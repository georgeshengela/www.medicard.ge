## Navigation before the shell mounts (2026-09-27, app 1.0.0.13.21)

expo-router wraps `app/_layout` in its own root stack, and AuthGate renders no `Stack` until auth/theme are ready. A `router.push` in that window does not fail: it pushes a second copy of the whole root layout (new providers, new AppShell). That is how a notification tap on a cold start looped on the splash with a flickering status bar. Never navigate from AppShell-level code, listeners or timers until `canOpenNotificationRoute` (segments non-empty, not `(auth)`) is true; `navigationRef.isReady()` is always true and proves nothing. Notification taps are claimed once per process (`notificationTaps.ts`) and routes must pass `isNotificationRoute`. Keep the root `ErrorBoundary`: the production boot guard swallows fatals, so without it a render crash is a frozen screen.

## Cycle temperature from Health (train 1.0.0.20 — store build)

Brief §9 „მერე“ item 5, §4 convention #10. ## Pressable styles (NativeWind gotcha)

NativeWind v4 **silently drops function-form style callbacks on `Pressable`** — `style={({ pressed }) => ({...})}` is never invoked, so the button renders with NO styles (invisible white text, unstyled layout). Always use a static object/array: `style={{ ... }}`. For pressed feedback use NativeWind `active:` classes or skip it. New screens' routes also need `<Stack.Screen name="..." options={{ headerShown: false }} />` in `app/_layout.tsx`, or an ugly system header appears on top. The sweep is complete (verified 2026-09-27: 0 function-form Pressable styles; `CyclePressable` resolves function styles itself before building its array).

The map gets `{type:'weather', fx}`; `WEATHER_FX_JS` (`src/lib/run/weatherFx.ts`, a string — Hermes has no function source) is a 2D canvas above the Glow city: rain streaks in three depth layers leaning with the wind, splashes on the ground half, storm lightning (≥ 6 s apart, never under reduced motion), swaying snow, drifting fog; it swings with the camera bearing and thins itself on a slow phone. It ships in the map HTML, so it goes by OTA (bump `RUN_MAP_HTML_REV`). The pill row on the map has one weather badge (icon · temperature · city; tap = one line with sky, wind, feels-like). Admin „ამინდი“ (`weather`) off = no fetch, no rain, no badge.

## MEDIRUN viral layer (owner 2026-10-05, app 1.0.0.21.7 — OTA + server only)

Owner: MEDIRUN must spread by itself — the beauty leaves the app, every share carries an invite, people bring friends. Rules (keep them):
- **Share clips** (`src/lib/run/shareStudio.ts` page + `src/components/run/ShareStudio.tsx`): a WebView renders the Glow city (or the box opening, 2D) into one 720×1280 canvas with the wordmark, numbers and the person's invite link (`shareLink()`: `medicard.ge/i/CODE` with a verified phone, else `/medirun`), records ~10 s with MediaRecorder (mp4 / quicktime only) and opens the share sheet; no mp4 recorder (Android WebView, old iOS) → the same final frame as a JPEG. Scenes: `walk` (summary → „გაზიარება“: camera follows the runner, then pulls back), `city` (hub „ჩემი ქალაქი ვიდეოდ“, one city only — `cityLines`), `box` (after a claim, „გააზიარე ვიდეოთი“), `wrapped`. **Privacy zone:** every line loses 200 m at both ends (`trimEnds`) before it is drawn; walks shorter than that fall back to the text share. Mapbox attribution is drawn on every map clip. Box art for the page lives in `server/public/medirun/glow/share/`. Web build: `ShareStudio.web.tsx` (buttons hide). Funnel `medirun_shared {kind, format}`. Check headless with Playwright (`--use-angle=d3d11` for GPU) — the in-app browser pane pauses rAF when hidden.
- **Starter box** (`server/src/lib/medipulsi/starter.js`): an account that never opened a box gets one personal box where it stands after `economy.starter.afterMeters` (60) or `afterSeconds` (45) of a fresh precise walk; `coins` 50, gift id `starter-<hash>` — visibility is decided by the id (`visibleTo`), never by the rule cache. Hidden from `/drops`, every admin list/map and the Director; never ranks (`reward.starter`), counts in the season budget, not placed once the budget is used up. The run screen announces it and opens the reveal by itself.
- **Crews** (`social.js`, raw-SQL `MedirunCrew` / `MedirunCrewMember` / `MedirunTogether`, created lazily, cascade with the account): ≤ 30 members, one crew per person, 6-char code (no 0/O/1/I), link `medicard.ge/crew/CODE` (`server/public/crew.html` → `medicard://run/crew?code=` → `app/run/crew.tsx` → hub join sheet). Members see nickname, role and this week's metres only. Names 2–24 chars, no links; admin „MEDIRUN ყუთები → გუნდები“ deletes a crew (audited `CREW_DELETE`).
- **Together**: in `nearby()` two crew members with fresh (≤ 20 s, ≤ 30 m accuracy) fixes within 40 m see each other's nickname („ერთად“ pill + haptic) — never a position; settings `together:false` hides you both ways. Together metres count only between ticks ≤ 30 s apart at walking speed (≤ 4.5 m/s) on the same Tbilisi day; each full km pays `economy.together.coinsPerKm` (10) up to `dailyCap` (30), ledger `together:<ymd>:<km>` (idempotent), stops with the season budget.
- **City meter** (`cityMeter.js`, `MedirunCityStat`): union of everyone's painted cells inside the campaign city, recomputed ≤ every 10 min under the `medirun-city-meter` lease; milestones 0,25 … 100 % (first run back-fills silently, later ones send a Director Telegram notice + audit `CITY_MILESTONE`). `GET /api/medipulsi/city` (app hub „თბილისი ერთად“) and public `GET /api/medirun/city` (the `/medirun` page section `#together`). No pushes to players on milestones without the owner.
- **Live counts**: `/drops` → `live.walkers` (active session, fix ≤ 2 min, inside the campaign city's bbox) and `live.rain` (near the running Saturday rain's centre); null below 3.
- **Wrapped** (`wrapped.js`, `GET /api/medipulsi/wrapped`): last Tbilisi week (metres, new streets, boxes, coins, ranks, Monday prizes), shown Monday–Wednesday on the hub as a flat card (the hero stays the one spotlight).
- Economy knobs live in admin „წესები → ეკონომიკა“ (`economy.starter`, `economy.together`; defaults in `medirun-campaign.json`, merged by `economyOf` — no `economy.version` bump, so the owner's saved days/waves stay). Privacy §4 describes crews, together, the aggregates and the share clips. Tests: `server/src/lib/medipulsi/social.test.js`, `mobile/src/lib/run/shareStudio.test.ts`, `bridgePolicy.test.ts`.

## MEDIRUN city decor (owner 2026-10-05, app 1.0.0.21.5)

Owner: make the night city something people cannot stop looking at. A separate script beside the engine, never inside `glow-engine.js`: `brand/medirun/glow/decor/` (`glow-decor.js` trucks + venues, `ferris.js` the Mtatsminda wheel, `runtime.js` entry) → `node brand/medirun/glow/decor/build.mjs` → `server/public/medirun/glow/decor/` (`decor.js` global `MedirunDecor`, `decor.json`, models). `mapHtml.ts` `startDecor()` sets `window.__MEDIRUN_THREE__ = glow.debug.THREE` and loads `decor.js` (the build maps every `three` import to that instance — never bundle a second three.js). Served no-cache like the engine, so decor fixes are server-only; the loader itself needed OTA 1.0.0.21.5 (`RUN_MAP_HTML_REV` 24). Tbilisi only (nothing is fetched elsewhere), fails silently.
- **Holiday trucks:** realistic Meshy truck (owner rejected code-built models), cut into tractor + trailer so it bends through turns (front axle on the lane, trailing drive axle and trailer axle), slows before bends; coloured chase bulbs, wreath, headlight beams, „გაანათე თბილისი“ picture on the trailer sides, gold dust. Owner: **only Rustaveli Avenue**, a loop Freedom Square ⇄ Philharmonic (First Republic Square) — `build-route.py` from saved OSM ways (`osm-rustaveli.json`; Rustaveli is `highway=construction` in OSM, so it is not in Mapbox's road graph). No Coca-Cola logo or trade dress without a contract; the trailer side is a sponsor slot.
- **Mtatsminda Ferris wheel:** exact geometry (Meshy melts spokes), real OSM spot, axle facing Freedom Square, ~6 000 LEDs cycling five shows every 11 s. The map is flat: it stands at ground level.
- **Partner venues:** McDonald's Rustaveli (Kakabadze 1) — Meshy model from the owner's photo of the real rotunda; the engine's own block under the OSM footprint is collapsed; neon arches over the dome, searchlights. Night material: never light pixels by per-pixel colour tests on a generated texture (speckles) — gate with a blurred sample and use a height floodlight.
- **Admin switches:** `medirunDecor` (trucks + wheel, on) and `medirunPartners` (partner buildings, `defaultOff: true` — a missing row means OFF; switch on only after the partner signs: their logo is a trademark). App Store: a partner placement must read as a partnership („პარტნიორი“).
- Lab: `brand/medirun/glow/decor-lab.html?nosim&follow=0` on preview `medirun-glow` (partners always on there). Model studio: `decor/studio.py` (OpenRouter concept → Meshy API direct, `MESHY_API_KEY` in `game-studio/.env`; `--ref photo` for real buildings) → `npx gltf-transform optimize … --compress meshopt --texture-compress webp`.

## MEDIRUN Glow map (2026-10-01, app 1.0.0.18.6)

Owner-approved after testing the prototype on an iPhone 15 Pro Max (solid 60 fps). The MEDIRUN map is a dark miniature city that lights up around the runner; the screen chrome of `PulseActive` stays exactly as it was — the only addition is the amber „N ანთია“ pill beside the mission pill (owner rule: do not restyle the buttons/cards). Engine source: `brand/medirun/glow/engine/glow-engine.js` (three.js custom layer in Mapbox's GL context: z16 streets-v8 tiles streamed around the camera → buildings with shader windows, trees, water glints; current trail ribbons + lamps; earlier walks light instantly; time-based light wave; rigged runner with x-ray silhouette). Build with `node brand/medirun/glow/engine/build.mjs` (needs `npm install` in that folder) → `server/public/medirun/glow/engine.js` + `runner-m.glb` / `runner-f.glb` (glTF-Transform-merged Meshy models; man and woman are the owner's approved characters — never regenerate or restyle them). `mobile/src/lib/run/mapHtml.ts` loads the engine from `GLOW_BASE` (medicard.ge, CORS) with `?v=RUN_MAP_HTML_REV` — bump the rev when the engine changes; without the engine it falls back to a plain night map + puck. Messages added to `RunMapMessage`: `init.hero` (`'f'` for FEMALE users), `init.runner:false` (summary map), `activity` (`auto`/`idle`/`dance`), `layout` (native chrome insets); the WebView posts `lit` (buildings lit this session). The map is always the night city regardless of theme. Prototype for further tuning: `brand/medirun/glow/index.html` (`python -m http.server 4460` there; same engine via import map). Headless checks: Playwright + swiftshader (`server/node_modules/playwright`).

Lighting pass (owner-approved 2026-10-04, app 1.0.0.20.40): bloom as a post pass inside the custom layer (`createPost`: `renderer.copyFramebufferToTexture` of the finished frame, bright pass at 1/4, blur at 1/4 and 1/8, one composite quad with a soft shoulder and vignette; it saves and restores Mapbox's framebuffer binding and must stay a single full-screen pass — never a second geometry pass); plaster-coloured facades lit from the nearest stretch of the trail (`aSeg` capsule light, falloff up the wall, windows switch on from the street upward); window kinds (tungsten / warm white / cool LED / TV flicker / curtains / balcony doors, sill spill, neon shop signs, sleepless windows in the dark city — shops mostly shut); instanced lamp posts (`POST` with `aGlass`, sodium warm-up, light cone `CONE`, arm toward the path, never inside a building); ignition motes; red beacons on buildings ≥ 32 m; road casings. `createGlow` options `bloom` / `adaptive` / `onQuality`: the pass turns itself off for the session after 3 s above 30 ms/frame, on a GL error, or when the first frames come back black (`post.verify`). `engine.js` and the runner models are served `no-cache`, so a rebuilt engine reaches phones on their next run; bump `RUN_MAP_HTML_REV` only when the WebView HTML itself changes. Render tools: `brand/medirun/glow/tools/` (`shoot.cjs` stills, `ignite.cjs` dark→lit frame sequence, `sheet.py`, `gif.py`); swiftshader renders show speckle inside windows and 4–7 fps — the software renderer, not a regression.

City detail + landmarks (owner 2026-10-05, server-side only — reaches phones with the no-cache engine, no app update). Bridges come from Mapbox (`structure: bridge`, every city): decks with ramps, fascia, piers, lamps; the trail, lamps and runner climb onto them (`deckZ`; a road crossing under keeps the ground). Water is one shader for every river/lake plus ribbons for Mapbox `waterway` lines; lit buildings/lamps/bridges near water leave streaks from the shore toward the viewer (shore found by marching water triangles, ≤ `WATER_LIGHTS`). OSM detail tiles (`node brand/medirun/glow/detail/build-detail.mjs` → `server/public/medirun/glow/detail/14/x/y.json`, Tbilisi): roof shapes matched by OSM way id (Mapbox building ids are OSM way ids), church parts as floodlit stone (`marks`), monuments (skipped where OSM already models them as building parts), fountains, city walls, lattice towers. Hero landmarks (`detail/landmarks.json` + `detail/models/*.glb`, made with `brand/medirun/glow/landmarks/landmark.py`: OpenRouter concept → Meshy → `gltf-transform optimize --compress quantize --texture-compress webp`): Peace Bridge (fitted to the OSM canopy outline way 440933580, deck 7.5 m), Metekhi church on its rock, Gorgasali statue, TV tower (own paint only, `look: paint` — the owner removed its MEDIRUN lamps, they read badly from afar), Freedom Square (`plaza`: platform, lawns, sett ring road, lamps and the column built in code from OSM part heights) with St George (8 m, `alwaysLit`). Keys: `from/to` (bridge) or `at` + `fitWidth|height`, `levelAt/level`, `front` + `facing`, `standOn` (raycast onto another hero), `replaces` (OSM ids), `clearsAll/clearsTall` (radius), `replacesMonument/replacesTower`, `look` (`canopy` | `flood` | `paint` | `medirun`). Every hero material needs `customProgramCacheKey` per look (three.js caches onBeforeCompile by source text). Preview: launch config `brandbook` (:4471) → `/brand/medirun/glow/index.html` (reads the detail tiles from the server folder).
