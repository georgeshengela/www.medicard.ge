## Daily AI quota reset + refill ping (39.0.14)

Unused credits (e.g. leftover 1/3 sitting for days) now reset at the next Tbilisi midnight. Hitting 0/3 still starts a 24h lock from that exact moment — midnight does not unlock early.

Refill notification:
- Server sweeper every 30s sends Expo push (`quota-reset` / `quota-reset-lock`) and `usage:reset` socket.
- Quiet hours (22:00–08:00 Tbilisi) delay the ping to 08:15; the quota itself is already open.
- Client schedules a local backup at the same instant; duplicate banners are suppressed.
- In-app `QuotaReadySheet` (“ლიმიტი განახლდა” → ჰკითხე Medi-ს) when credits come back.

Stale leftover rows with no `resetAt` (old open-window model) zero immediately on the next `getUsage`. Additive `PeriodUsage.notifyAt`; runtime `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` so we don't `db push` (that currently wants to drop `UserLocation`).
