## Android Health Connect (real device APK)

iPhone HealthKit worked; installed Android build could not connect to Health Connect.

Cause: `react-native-health-connect` Expo plugin only injects the permission-rationale activity. The APK never declared `android.permission.health.READ_*` / `WRITE_*` or a `<queries>` entry for `com.google.android.apps.healthdata`. Without those, `getSdkStatus()` looks like "not installed" and `requestPermission()` returns `[]`.

Fix in 20.0.36:
- `mobile/plugins/withHealthConnect.js` injects health permissions + package query
- same permissions listed in `app.json` `android.permissions`
- Android connect opens Play Store if Health Connect is missing, and Health Connect settings if the grant list is empty
- Needs a **new Android binary**. Metro/OTA will not pick this up.
