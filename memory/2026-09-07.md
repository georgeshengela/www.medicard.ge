  - `RunTargetSheet.tsx`: CTA static style (was invisible), custom-value chip now flexGrow full-width (placeholder no longer truncated), more bottom padding.
  - `app/run/index.tsx` hero CTA + `HomeRunSection.tsx` card wrapper → static styles.
  - Version 32.0.0 → 32.0.1.
- **E2E verified on emulator via adb** (screencap + input tap): login QA user (+995500000005 / OTP 0000, deep link `exp://127.0.0.1:8081/--/phone`), home → hub → sheet → pin drop (Mapbox route drawn) → START → simulation movement (time/distance/pace/kcal/steps counting) → finish confirm → summary → home card shows last run. All screens look right now.

## Medi Run v33.0.0 — game chase-cam + vehicle detection

- **Chase cam (mapHtml.ts):** while following — zoom 18.3, pitch 67, bottom padding 44% so the runner puck sits lower-third and the lane stretches ahead; camera bearing = heading. Route drawn as a road-lane (glow + casing + solid teal + animated white flowing dashes via Mapbox dasharray ant-line, 75ms step). Route ahead trimmed per fix (pointer advances along vertices; lane = [current pos, ...rest]). Trail recolored amber. New SVG markers: teal glossy puck + white nav chevron (rotates with heading); hand-crafted glossy 3D amber pin (SVG gradients) with light beam, pulsing ground halo, bob animation; captured → hue-rotate to green + pop.
- **CRITICAL Mapbox gotcha:** programmatic `easeTo` with bearing change fires `rotatestart`/`dragstart` too — a naive "user interacted → stop following" handler instantly kills follow. Must check `e.originalEvent` (only set for real gestures).
- **Speed + transport detection (store.ts):** raw speed computed per fix BEFORE the GPS-jump filter (which rejects >43 km/h fixes from distance); EMA-smoothed `speedKmh` in state, shown next to the clock in the HUD. Sustained >25 km/h: warn at 12s (amber banner "ძალიან სწრაფად მიდიხარ 🚗" + amber speed), auto-cancel at 32s (`cancelForTransport` → phase idle + `transportCancelled`, modal with car icon explains walking/running only, run NOT saved). <18 km/h decays the counter 2×.
- **Dev sim now 3 modes:** off → run (10.4 km/h) → drive (48.6 km/h, red chip "სიმ · მანქანა") — drive mode used to E2E the warning + auto-cancel live on the emulator.
