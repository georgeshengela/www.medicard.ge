როგორ გამოვიყენო?

აირჩიე პოსტერი, შეცვალე ტექსტი და ჩამოტვირთე PNG. საიტის ხელნაწერი ფონტი სათაურებისთვისაა; აღწერებისთვის FiraGO დატოვე.

პროექტის ფაილი ინახავს ყველა პოსტერის ტექსტს, ფერსა და მდებარეობას. სურათები და ფონტები MEDICARD-ის ადმინში რჩება.
