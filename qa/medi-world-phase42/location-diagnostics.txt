## Failing boundary (original PARTIAL)

1. Emulator `geo fix` returned OK while GPS was idle (`mStarted=false`). dumpsys last-location timestamp did not change.
2. Explore requested `Accuracy.Balanced`, so Fused did not start GPS (network last location null).
3. `getCurrentPositionAsync` raced 8–12s and timed out.
4. Failure was not “need a longer timeout”; it was accuracy option + idle GPS so injection never landed.
