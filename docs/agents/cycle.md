## Cycle on the lock screen (train 1.0.0.20 — store build)

Brief §8.7 / §9 „მერე“, Discreet rule [კ-32]. Everything here needs the train-20 binary (widget extension `ge.medicard.app.widgets`, app group `group.ge.medicard.app`, alternate icons); older binaries see nothing.
- **Widget „MEDICARD ციკლი“** (small + medium, `expo-widgets` entry `MedicardCycle` in app.json): layout `src/lib/cycleWidgetLayout.tsx` (`'widget'` directive, props only), words from the pure `src/lib/cycleWidgetSnapshot.ts`, controller `src/lib/cycleWidget.ts` (started from the root layout on iOS) writes a 14-day timeline (then the neutral tile) on every cycle-view cache change, foreground, account change, module switch and privacy switch (`signalCycleWidget`). Look (owner pick 2026-10-04, variant A of `brand/cycle/widget/widget-variants.html`, ships by OTA): the real MEDICARD logo as PNGs (`node brand/cycle/widget/render-art.cjs` → `mobile/assets/widget/cycle/`), copied by `src/lib/cycleWidgetArt.ts` into the expo-widgets app group folder (`widgetsDirectory`, versioned `cycle-art-vN` — bump it when the art changes) and passed as `props.art`; the ornament PNG is the whole tile and undoes `widgetContentMargins` with negative padding. Never rebuild the logo from shapes (owner: „საშინელება“ — the 1.0.0.20.10 attempt). Period family only — countdown / variable window / „დღეს“ / „მენსტრუაციის დღე N“ / late / „ვსწავლობთ“ / „თვალყურის დევნება“; never fertile, ovulation, sex, BBT, tests, pregnancy (neutral) or postpartum words, never the turquoise; `CYCLE_WIDGET_FORBIDDEN` is checked by tests. **Discreet is automatic:** cycle lock, privacy mode, masked cycle notifications, Medi discreet notifications or her own „ვიჯეტზე ციკლის დამალვა“ → „MEDICARD“ + a dot; the own switch is forced on (disabled) while any of the others is on. Sign-out / another account / cycle module paused → neutral at once (`medicard.cycle.widget.owner` remembers whose data is shown). Never add a cycle word to the layout itself.
- **„დაიწყო“** = `medicard://cycle?periodStart=1`: `app/+native-intent.tsx` keeps expo-router from opening it, `src/lib/cycleWidgetLink.ts` claims it once per day (`claimNotificationTap('widget:periodStart:<ymd>')`), the root layout opens it through the notification queue (`canOpenNotificationRoute`), the cycle privacy gate runs, then `/cycle` does the one-tap start with the undo toast when `cycleWidgetStartAllowed`. Funnel source `widget` (server `CYCLE_PERIOD_START_SOURCES`).
- **Expected-day Live Activity** (`CycleDayActivity`, `src/lib/cycleDayActivityLayout.tsx`, off by default, cycle settings → შეხსენებები „სავარაუდო დღე ჩაკეტილ ეკრანზე“): starts only from the foreground on the expected day / the window's first day, once per day (`shownFor`), same words and discreet rules, ends when bleeding is logged, the switch is off or after 24 h (iOS itself ends Live Activities after ~8 h + 4 h on the lock screen).
- Tests: `tests/cycle-widget.test.cjs` (layouts in the expo-widgets runtime), `src/lib/cycleWidgetSnapshot.test.ts`, `src/lib/cycleWidgetLink.test.ts`.

## Cycle temperature from Health (train 1.0.0.20 — store build)

Brief §9 „მერე“ item 5, §4 convention #10. Cycle settings → პროფილი (TRACK_PERIOD / TTC) „ტემპერატურა Apple Health-იდან“ / „Health Connect-იდან“ (`useCycleTemperatureSetting` in `CycleTemperatureRow.tsx`): off by default, acts at once; turning it on shows the one-button „გაგრძელება“ primer (`primerCopy('temperature')`, in-window overlay, once per device) and only that tap asks the OS (`connectHealthTemperature` → iOS read BBT + `AppleSleepingWristTemperature`, Android read `BasalBodyTemperature` + `SkinTemperature` + history; `READ_SKIN_TEMPERATURE` in app.json and `plugins/withHealthConnect.js`; the iOS share string mentions temperature, still Georgian only).
- Import (`cycleTemperatureSync.ts`, pure rules in `cycleTemperatureImport.ts`): on /cycle focus, ≤ 1× per 6 h per account (`cycleTemperature.lastImportAt.<userId>`, written before the read), never from background, never requests access. Last 40 days; °F → °C; BBT 35–39 (first reading of the day); samples Medicard wrote itself are skipped. `POST /api/cycle/temperature/import` (server `planTemperatureImport`): her typed BBT always wins; imported BBT carries `observations.bbtSource: 'health'`; wrist / skin temperature is stored only as `observations.wristTempDelta` (°C deviation, iOS = deviation from her median) and never as BBT. Both keys SENSITIVE, never AI / partner / analytics / doctor summary, written by the import only (`PUT /logs` strips them; a typed BBT change clears `bbtSource` — server `bagAfterTypedBbt`, offline `typedBbtBag`). A day with only imported temperature draws no „logged“ dot; an unchanged imported BBT is never written back to Health.
- Retrospective ovulation (`server/src/lib/cycleTemperature.js` mirrors `cycleTtcSignals.findThermalShift`; one table `cycleTemperature.cases.js` runs on both sides): a „3 over 6“ shift in BBT (else wrist) → ovulation = the day before the first high reading, `ovulationSource: 'temperature'`, `fertility.retrospective`, label „ტემპერატურის მიხედვით · რეტროსპექტულად“. Precedence manual mark > OPK > temperature > calendar. It never moves the next period; completed cycles' own signals teach the luteal length (`pastOvulations` / `learnedLutealDays`: ≥ 2 cycles, median kept 10–16) used only for the calendar ovulation ahead (`fertility.lutealDays`, `fertility.pastOvulations`; stripped by contraception and in the partner view). The TTC card shows „წინა ციკლში ოვულაცია სავარაუდოდ … · ტემპერატურის მიხედვით · რეტროსპექტულად“; the TTC line falls back to „მაჯის ტემპერატურა N ღამეა მომატებულია …“.
- Android `ANDROID_SYNCHRONOUSLY_UPDATE_UI_PROPS` is on via `mobile/package.json` `reanimated.staticFeatureFlags` (brief §8.6 [კ-13]) — read by reanimated's gradle/podspec at build time, so it needs a native build; never enable `ENABLE_SHARED_ELEMENT_TRANSITIONS` with it.
- Tests: `src/lib/cycleTemperatureImport.test.ts` (importer, throttle, permission-from-button guard, config), `cycleTtcSignals.test.ts` (shared table, wrist line), `server/src/lib/cycleTemperature.test.js`.

## Cycle look (2026-09-28, app 1.0.0.17.7)

Owner-requested redesign, UI only (no new phases, honesty rules unchanged). Palette `src/theme/cyclePalette.ts` speaks the colour language women already know from Flo / Apple Health, because there is no Georgian cycle app and every user migrates from one of those: **rose-red** bleeding (solid = logged, dashed = expected), **turquoise** fertile window / ovulation (`fertileFill` for graphics), rose actions, today in calm ink, blush-white canvas. Owner rejected an earlier clay/blue/teal set as ugly and unfamiliar. Contrast is enforced by `tests/cycle-palette.test.cjs`. One grammar on ring, strip and calendar: logged bleeding = solid clay circle, estimated period = dashed clay ring, estimated fertile = soft turquoise circle with turquoise number, estimated ovulation = soft turquoise + turquoise ring, logged symptoms = small dot under the date — no bands or abstract lines (the owner found a band unreadable). The legend draws tiny day circles. Layout: the week strip is a card inside the 20 px gutters and is the only pinned element (header and tabs scroll away); the selected day (today by default) sits in the middle column with three days either side, and a „დღეს“ pill appears once today scrolls out of view. The hero ring (`CycleStatusGauge`) is one bead per cycle day sitting on soft phase bands (rose bleeding, turquoise fertile, lilac after it — all in the legend), a centre glow tinted by today's phase and a slowly breathing today marker (still under reduced motion), with one number in the centre (bleeding day → „დღეს“ → countdown with „სავარაუდოდ“ → cycle day); „მენსტრუაცია დაიწყო“ leads only when the period is plausible within 3 days, unknown or late. Cards are flat hub cards; no decorative arcs.

Owner reported none arriving: they were OFF by default, scheduled only when the cycle screen loaded, and masked by default („Medi-სგან შეხსენება“, unrecognisable). Now: `enabled` defaults ON, `maskNotifications` defaults OFF (real text like Flo / Apple; masking stays one switch in cycle settings, and privacy mode / discreet still mask), and `reconcileCycleReminders` runs on sign-in/cold start and every foreground (≤ every 10 min) from `AuthContext` for female users; feature flag `cycle` off cancels them. ## Cycle brief waves 1–3 (2026-10-03/04, app 1.0.0.19.6)

Built from the MEDICARD Cycle brief (artifact); local commits `c36c053..HEAD`, server changes must deploy (plus `db:install`) before the OTA. Keep these rules:
- **Reminders:** default-on family = period soon / today / late (late = window end + 2 days, owner 2026-10-04); ovulation, PMS, daily log default off (TTC turns ovulation/fertile on). Default texts never contain ნაყოფიერი/ოვულაცია/სექსი/ლიბიდო/გამონადენი (tests on app copy and `server/src/lib/pushTemplates.js`, which mirrors the app; `cycle-period-late` exists). `LEGACY_SERVER_CYCLE_COPY` stays until no stored admin row holds the old text.
- **Forecast honesty (server `cycleForecastHonesty.js`, mirror `mobile/src/lib/cycleForecastEligibility.js`, identical tests):** fertile window/ovulation only after 3 completed logged cycles („ვსწავლობთ შენს რიტმს · N/3“), TTC gets a wide 14-day window before that; ovulation is a 3-day band (`ovulationRange`, `ovulationDate` kept for old builds); a positive OPK centres it on D+1, the manual mark `observations.ovulationMarked` (SENSITIVE) wins; variable cycles carry `nextPeriodRange` and „late“ starts only after the range — every screen shows the whole range. Stats verdicts need 3 cycles.
- **Period auto-end (`cyclePeriodStatus.js`):** derived at read time, never written; day typical+1 asks „ჯერ კიდევ გაქვს?“ [კი · დასრულდა]; the one-tap end stores flow „none“ on that day.
- **Tracking:** `CycleProfile.expectsBleeding` + `fertilityDisplay` (raw SQL `@ignore` columns, `install-cycle-tracking.mjs`) through `cycleModeCapabilityMatrix.js` (server and mobile copies identical) — no forecast/late/countdown/period reminders when bleeding is not expected; fertile display forced on in TTC, off under hormonal contraception.
- **Deviations card** (`server/src/lib/cycleDeviations.js`, /cycle only): Apple's 6-month rules, nothing at all before 180 days + 3 cycles, paused by pregnancy/postpartum (< 90 days) and current hormonal contraception, last line „ეს დიაგნოზი არ არის — ესაუბრე ექიმს“; never a condition name.
- **Logging:** full log = one list with jump tabs (owner 2026-10-04); BBT only through `CycleBbtPicker` (opening it logs nothing — scroll, tap or „ეს მნიშვნელობა“); pain strength by re-tap or long-press pill; „კატეგორიების მორგება“ per device; „გაიგე მეტი“ texts in `src/i18n/cycle/learnMore.ts` (no entries for sex ids; sources in `medicalSources.ts`; needs a Georgian clinical read before claims change); pregnancy checklist ticks in `observations.pregnancyChecklist`.
- **Privacy:** health text never travels in a route — Medi drafts and log notes go through `src/lib/mediHandoff.ts` / `cycleLogHandoff.ts` (account-bound, 60 s, read once; guard tests scan for `prefill=`/`prefillNote=` built from values). Medi's cycle context (`cycleMediContext.ts`) carries only cycle day, phase, forecast and today's pain/mood, filtered by the registry; nothing when the cycle lock, privacy mode or discreet notifications are on; the person sees and can remove it before sending. TTC signals from BBT/OPK/mucus (`cycleTtcSignals.ts`) stay on /cycle and today's day sheet only (import allow-list test). Declining AI consent is a calm „AI-ს არაფერი გაეგზავნა…“ line with „ხელახლა ცდა“, never an error box. Cycle funnel events (`cycle_log_saved`, `cycle_period_started`, `cycle_explain_opened`) are anonymous: enum value + Tbilisi day only, no user/install id, sent in their own batches.
- No `Alert.alert` in cycle screens (`CycleExplainSheet`); cycle settings = hub + `/cycle/settings/{profile,reminders,privacy,data}`; cycle sub-screens read through `src/lib/cycleQueries.ts` (TanStack).
- **Wave 3 (main):** a cycle can be hidden from averages (`CycleProfile.hiddenCycles`, raw SQL, `install-cycle-hidden-cycles.mjs`; hidden cycles never count toward the 3-cycle gate, stay visible in the calendar). Perimenopause never shows one date: `perimenopause.forecast` range / learning / long_gap / no_bleeding_12m, only the „მალე“ reminder, no late state. „ბოლო ციკლები“ comparison is against her own median, never population norms. The doctor report's symptom map takes only items the registry allows in the doctor summary (no moods). AI context is registry-driven (`observationAiContextAllowed`: row exists, `aiDefaultAllowed`, HEALTH sensitivity) — BBT, tests, mucus, sex and intimate fields never reach AI. Every AI caller handles a declined disclosure with `isAiConsentDeclined` + `AiConsentDeclinedNote` (guard `tests/ai-consent-decline-callers.test.cjs`); cycle insights never open the consent sheet on mount.
- **Train 1.0.0.20 (branch `feat/cycle-train-20`, not on main):** iOS cycle widget + „სავარაუდო დღე“ Live Activity (period words only, automatic discreet tile), Apple Health / Health Connect temperature (retrospective ovulation), reanimated Android UI-props flag, and the `feat/app-icons` icons merged in (the discreet calendar/flower icons were dropped by the owner). Merge it only with the next store build.
